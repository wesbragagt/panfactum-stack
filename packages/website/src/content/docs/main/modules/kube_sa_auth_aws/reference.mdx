## Inputs

The following input variables are supported:

### allow\_public\_s3\_presigned\_urls

Description: Whether to allow the service account to generate presigned URLs that will be publicly accessible

Type: `bool`

Default: `false`

### annotate\_service\_account

Description: Whether or not to annotate the service account

Type: `bool`

Default: `true`

### cluster\_name

Description: Explicit Kubernetes cluster name. Defaults to Panfactum kubeconfig metadata.

Type: `string`

Default: `null`

### cluster\_subnet\_ids

Description: Explicit cluster subnet IDs for IP restrictions. Null preserves tagged EKS subnet discovery; an empty set disables discovery.

Type: `set(string)`

Default: `null`

### custom\_oidc\_enabled

Description: Select custom OIDC at plan time when the provider ARN and issuer URL are created in the same plan.

Type: `bool`

Default: `false`

### iam\_policy\_json

Description: An IAM policy document in rendered JSON string form.

Type: `string`

Default: n/a

### iam\_tags

Description: Existing IAM base tags to preserve during state adoption. Defaults to Panfactum AWS tags.

Type: `map(string)`

Default: `null`

### ip\_allow\_list

Description: A list of IPs that can use the service account token to authenticate with AWS API

Type: `list(string)`

Default: `[]`

### ip\_restrictions\_enabled

Description: Attach Panfactum source-IP deny policies (default true). Explicit false supports self-managed nodes with changing public egress; OIDC principal/subject/audience restrictions remain enforced.

Type: `bool`

Default: `true`

### local\_static\_credentials\_enabled

Description: Development simulators only: create an IAM user, access key and Kubernetes Secret <service\_account>-aws-static instead of IRSA/EKS discovery. The role trusts only that user. Never use against real AWS.

Type: `bool`

Default: `false`

### oidc\_issuer\_url

Description: HTTPS issuer URL paired with oidc\_provider\_arn. Custom identities require the exact namespace/service-account subject and sts.amazonaws.com audience.

Type: `string`

Default: `null`

### oidc\_provider\_arn

Description: Existing self-managed cluster OIDC provider ARN. Supply with oidc\_issuer\_url; null preserves EKS discovery.

Type: `string`

Default: `null`

### service\_account

Description: The name of the service account that should be able to assume the AWS permissions.

Type: `string`

Default: n/a

### service\_account\_namespace

Description: The namespace of the service account.

Type: `string`

Default: n/a

## Outputs

The following outputs are exported:

### local\_credentials\_secret\_name

Description: Secret holding AWS\_ACCESS\_KEY\_ID/AWS\_SECRET\_ACCESS\_KEY when local\_static\_credentials\_enabled; null otherwise.

### local\_user\_arn

Description: IAM user ARN behind the local static credentials; null otherwise.

### policy\_arn

Description: The ARN of the policy assigned to the role.

### role\_arn

Description: The ARN of the role created for the service account.

### role\_name

Description: The name of the role created for the service account.

### service\_account\_annotations

Description: The annotations to apply to the service account

## Inputs

The following input variables are supported:

### cluster

Description: Talos cluster identity and service-account OIDC trust, as output by aws\_kube\_talos.

Type:

```hcl
object({
    name              = string
    oidc_provider_arn = string
    oidc_issuer_url   = string
  })
```

Default: n/a

### controller\_provider\_ids

Description: AWS provider ID of each controller keyed by private IP, as output by aws\_kube\_talos.

Type: `map(string)`

Default: n/a

### image\_version

Description: AWS cloud controller manager image tag. Use the release for the cluster's Kubernetes minor.

Type: `string`

Default: `"v1.36.1"`

## Outputs

The following outputs are exported:

### role\_arn

Description: n/a

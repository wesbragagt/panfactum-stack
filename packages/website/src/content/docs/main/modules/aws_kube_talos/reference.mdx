## Inputs

The following input variables are supported:

### ami\_id

Description: Optional custom Talos AMI ID.

Type: `string`

Default: `null`

### api\_dns

Description: Optional public DNS name for the Kubernetes API. Creates an A record to the Elastic IP in this Route53 zone and makes the name the cluster endpoint.

Type:

```hcl
object({
    zone_id = string
    name    = string
  })
```

Default: `null`

### aws\_ccm

Description: AWS cloud controller manager settings. Set host\_networking to false while adopting an existing pod-network release.

Type:

```hcl
object({
    image_version           = optional(string)
    host_networking         = optional(bool, true)
    subnet_id               = optional(string)
    availability_zone       = optional(string)
    ip_restrictions_enabled = optional(bool, false)
    cluster_subnet_ids      = optional(set(string))
    iam_tags                = optional(map(string))
    helm_values             = optional(string, "{}")
    operator_kube_port      = optional(number, 16443)
  })
```

Default: `{}`

### bootstrap\_control\_plane

Description: Subnet name of the controller that runs talos\_machine\_bootstrap and serves as the cluster endpoint fallback. Null uses the first entry of control\_plane\_subnets. Must be one of the active subnets.

Type: `string`

Default: `null`

### bootstrap\_public

Description: Overrides for the temporary public NLB. Public transport enables it and detects the runner's public IPv4 address by default. Set operator\_cidr to override discovery. Set enabled to false after verifying private access to retire the public NLB.

Type:

```hcl
object({
    enabled       = optional(bool, true)
    operator_cidr = optional(string)
  })
```

Default: `null`

### cilium\_enabled

Description: Disable Talos-managed Flannel and kube-proxy on every node before installing Cilium with kube-proxy replacement.

Type: `bool`

Default: `true`

### client\_configuration

Description: Talos admin client credentials (base64 CA, certificate, key) that Terraform uses for the Talos API. Signed by the os CA in machine\_secrets; produced by scripts/gen\_talos\_secrets.py.

Type:

```hcl
object({
    ca_certificate     = string
    client_certificate = string
    client_key         = string
  })
```

Default: `null`

### cluster\_name

Description: The name of the Talos cluster. Used for the Talos/Kubernetes cluster name and AWS resource names.

Type: `string`

Default: n/a

### control\_plane\_config\_patches

Description: Additional Talos configuration patches for control plane nodes.

Type: `list(string)`

Default: `[]`

### control\_plane\_count

Description: Number of on-demand control plane nodes, placed in control\_plane\_subnets order. Above 1 requires private\_api\_dns\_name so nodes do not depend on one controller's address.

Type: `number`

Default: `1`

### control\_plane\_instance\_type

Description: EC2 instance type for control plane nodes. T2 types are not supported by Talos.

Type: `string`

Default: `"t4g.medium"`

### control\_plane\_instance\_types

Description: Optional per-node instance types in control\_plane\_subnets order, overriding control\_plane\_instance\_type. A change resizes that controller in place (stop, modify, start).

Type: `list(string)`

Default: `[]`

### control\_plane\_private\_ips

Description: Optional fixed private IPs for control plane nodes, one per node in control\_plane\_subnets order. A fixed address lets an SSM tunnel target the controller before it exists, so the first bootstrap needs no public ingress. Changing it replaces the nodes.

Type: `list(string)`

Default: `[]`

### control\_plane\_public\_ip\_enabled

Description: Give controllers a public IP and an Elastic IP API endpoint. Off by default: controllers sit in private subnets and operators reach them through an SSM tunnel, which needs private\_api\_dns\_name or control\_plane\_private\_ips.

Type: `bool`

Default: `false`

### control\_plane\_subnets

Description: Subnet names (Name tag), one per control plane node in order. Use PUBLIC subnets only with control\_plane\_public\_ip\_enabled. Names must be unique. Node state is keyed by list position, so only append entries; reordering or removing one replaces nodes.

Type: `list(string)`

Default:

```json
[
  "PRIVATE_A",
  "PRIVATE_B",
  "PRIVATE_C"
]
```

### control\_plane\_workloads\_enabled

Description: Whether controllers join the Panfactum controller class: they get the panfactum.com/class=controller label, lose the default control-plane taint and get the controller=true:NoSchedule taint. When false, controllers keep the default Talos control-plane taint and no class label.

Type: `bool`

Default: `true`

### controller\_identity

Description: IAM naming and ECR access settings for the optional Talos controller identity.

Type:

```hcl
object({
    name_prefix                            = optional(string)
    ecr_cache_prefixes                     = optional(set(string), [])
    controller_instance_profile_enabled    = optional(bool, false)
    controller_additional_ecr_repositories = optional(set(string), [])
  })
```

Default: `null`

### controller\_instance\_profile

Description: IAM instance profile name for controllers. Changing it on a running controller re-associates the profile in place.

Type: `string`

Default: `null`

### controller\_provider\_id\_kube\_api\_server

Description: Optional HTTPS Kubernetes API URL for setting AWS controller provider IDs. VPN and public access derive the URL automatically. For SSM, keep a Kubernetes forward running and set its loopback URL to enable provider ID reconciliation.

Type: `string`

Default: `null`

### core\_dns\_enabled

Description: Whether Talos deploys its own CoreDNS. Disabled by default for Panfactum kube\_core\_dns.

Type: `bool`

Default: `false`

### etcd\_backup\_retention\_days

Description: Days to keep etcd snapshots in S3.

Type: `number`

Default: `7`

### etcd\_backup\_schedule

Description: Cron schedule for etcd backups in UTC.

Type: `string`

Default: `"0 * * * *"`

### etcd\_pre\_membership\_snapshot\_enabled

Description: Run the etcd-backup CronJob and wait for it before creating controllers that join an existing cluster.

Type: `bool`

Default: `true`

### etcd\_pre\_membership\_snapshot\_kubeconfig

Description: Path to a kubeconfig that reaches the API through the operator tunnel. Required only when an apply adds controllers to an existing cluster; kubectl must be on PATH.

Type: `string`

Default: `null`

### etcd\_pre\_membership\_snapshot\_timeout\_seconds

Description: Seconds to wait for the pre-membership snapshot job to complete.

Type: `number`

Default: `600`

### installer\_image

Description: Optional Talos factory installer image matching the AMI.

Type: `string`

Default: `null`

### kube\_api\_allowed\_cidrs

Description: CIDRs allowed to reach the Kubernetes API (TCP 6443) on the control plane's Elastic IP.

Type: `list(string)`

Default: `[]`

### kube\_api\_extra\_sans

Description: Additional DNS names or IPs in the Kubernetes API certificate.

Type: `list(string)`

Default: `[]`

### kube\_api\_source\_security\_groups

Description: Security group IDs allowed to reach Kubernetes TCP 6443, keyed by stable caller-chosen names.

Type: `map(string)`

Default: `{}`

### kube\_version

Description: Kubernetes version (e.g., 1.36.5). Pinned so a talos provider upgrade does not change it; upgrade with `talosctl upgrade-k8s`.

Type: `string`

Default: `"1.36.5"`

### machine\_secrets

Description: Talos secrets bundle in the siderolabs/talos provider machine\_secrets shape. Generate it once with scripts/gen\_talos\_secrets.py and keep it SOPS-encrypted; it is the only source of the cluster PKI.

Type:

```hcl
object({
    certs = object({
      etcd               = object({ cert = string, key = string })
      k8s                = object({ cert = string, key = string })
      k8s_aggregator     = object({ cert = string, key = string })
      k8s_serviceaccount = object({ key = string })
      os                 = object({ cert = string, key = string })
    })
    cluster = object({ id = string, secret = string })
    secrets = object({
      bootstrap_token             = string
      secretbox_encryption_secret = string
      aescbc_encryption_secret    = optional(string)
    })
    trustdinfo = object({ token = string })
  })
```

Default: `null`

### operator\_tunnel\_security\_group\_ids

Description: Security groups of SSM tunnel hosts (for example one NAT per AZ) allowed to reach the private Kubernetes and Talos APIs.

Type: `list(string)`

Default: `[]`

### pod\_subnets

Description: Kubernetes pod network ranges.

Type: `list(string)`

Default:

```json
[
  "10.244.0.0/16"
]
```

### private\_api\_dns\_name

Description: Optional private DNS name (e.g. api.example.internal) used as the cluster endpoint. Creates a private Route 53 A record with every controller private IP. Clients handle failover between those addresses. Node-local components can use KubePrism.

Type: `string`

Default: `null`

### root\_volume\_size\_gb

Description: Size of each node's root EBS volume in GB.

Type: `number`

Default: `20`

### secrets\_bundle

Description: Decrypted talosctl secrets bundle, including clientconfig. Keep the source SOPS-encrypted.

Type: `any`

Default: `null`

### service\_subnets

Description: Kubernetes service network ranges.

Type: `list(string)`

Default:

```json
[
  "10.96.0.0/12"
]
```

### ssm\_jump\_host\_enabled

Description: Create an SSM jump host in the VPC that operators tunnel through to the private Kubernetes and Talos APIs.

Type: `bool`

Default: `false`

### ssm\_jump\_host\_instance\_type

Description: Instance type of the SSM jump host. Must support arm64.

Type: `string`

Default: `"t4g.nano"`

### ssm\_jump\_host\_subnet

Description: Name tag of the private subnet for the SSM jump host. Defaults to the first entry of control\_plane\_subnets.

Type: `string`

Default: `null`

### talos\_access\_transport

Description: Talos operator transport. bootstrap\_public selects the temporary public load balancer. vpn selects the configured bootstrap controller's fixed private IP. ssm selects the module hook's loopback address and enables loopback SANs. The empty default retains legacy loopback behavior.

Type: `string`

Default: `""`

### talos\_api\_allowed\_cidrs

Description: CIDRs allowed to reach the Talos API (TCP 50000). Empty by default; operators reach the API through the SSM tunnel instead.

Type: `list(string)`

Default: `[]`

### talos\_api\_endpoint

Description: Override the Talos API endpoint for the provider and talosconfig, with optional port. An empty string derives the endpoint from talos\_access\_transport. Null uses the Elastic IP and requires control\_plane\_public\_ip\_enabled.

Type: `string`

Default: `""`

### talos\_api\_extra\_sans

Description: Additional DNS names or IPs in the Talos API certificate. Include the endpoint name or IP if Talos does not discover it on boot.

Type: `list(string)`

Default: `[]`

### talos\_api\_source\_security\_groups

Description: Security group IDs allowed to reach Talos TCP 50000, keyed by stable caller-chosen names.

Type: `map(string)`

Default: `{}`

### talos\_version

Description: Talos version. Selects the official Sidero Labs AMI and the machine config contract.

Type: `string`

Default: `"v1.14.6"`

### vpc\_id

Description: The id for the VPC that the cluster should be deployed into

Type: `string`

Default: n/a

### worker\_identity

Description: Deprecated alias for the Talos controller identity settings. Worker IAM is managed by Karpenter.

Type:

```hcl
object({
    name_prefix                            = optional(string)
    ecr_cache_prefixes                     = optional(set(string), [])
    controller_instance_profile_enabled    = optional(bool, false)
    controller_additional_ecr_repositories = optional(set(string), [])
  })
```

Default: `{}`

## Outputs

The following outputs are exported:

### aws\_ccm\_bootstrap\_controller

Description: Identity to check before deploying Cilium. Null when the host-network bootstrap check is disabled.

### aws\_ccm\_role\_arn

Description: IAM role ARN for the integrated AWS cloud controller manager.

### bootstrap\_public\_host

Description: Temporary public hostname for the Talos and Kubernetes operator APIs. Null when the public load balancer is disabled.

### bootstrap\_public\_kube\_url

Description: Temporary public Kubernetes API URL for kubectl and Helm.

### bootstrap\_public\_node

Description: Private IP of the controller targeted by the temporary public load balancer.

### bootstrap\_public\_talos\_endpoint

Description: Temporary public Talos API address for talosctl, including the port.

### cluster

Description: Talos cluster connection metadata for Karpenter.

### cluster\_ca\_data

Description: Base64-encoded Kubernetes cluster CA certificate.

### cluster\_name

Description: The name of the Talos cluster.

### cluster\_region

Description: The AWS region to which the Talos cluster is deployed

### cluster\_url

Description: The URL of the Kubernetes API server (use as kube\_api\_server in region.yaml).

### control\_plane\_private\_ips

Description: Private IPs of the control plane nodes, in control\_plane\_subnets order.

### control\_plane\_public\_ips

Description: Public IP of the control plane node (Talos and Kubernetes API endpoint).

### dns\_service\_ip

Description: CoreDNS service address in the primary service CIDR when AWS node configuration owns the network.

### etcd\_backup\_bucket

Description: S3 bucket holding SSE-KMS encrypted etcd snapshots.

### etcd\_backup\_cronjob\_manifest

Description: CronJob YAML for Kubernetes-stage reconciliation after bootstrap. Contains Secret references, not credential values.

### etcd\_backup\_kms\_key\_arn

Description: KMS key that encrypts etcd snapshots. Restores need kms:Decrypt on it.

### kubeconfig

Description: Admin kubeconfig. The context is named admin@<cluster\_name>.

### kubernetes\_version

Description: Configured Kubernetes version for the Talos cluster.

### node\_bootstrap

Description: Cluster metadata for generating a Talos worker configuration outside this module.

### node\_security\_group\_id

Description: Security group shared by all Talos nodes.

### oidc\_issuer\_url

Description: Public service-account issuer; configure Talos to sign tokens with this issuer.

### oidc\_provider\_arn

Description: IAM OIDC provider for sts.amazonaws.com service-account tokens.

### ssm\_jump\_host\_instance\_id

Description: Instance ID of the SSM jump host, or null when ssm\_jump\_host\_enabled is false.

### ssm\_jump\_host\_security\_group\_id

Description: Security group of the SSM jump host, or null when ssm\_jump\_host\_enabled is false.

### talos\_ami\_id

Description: Talos AMI used by workers.

### talosconfig

Description: talosctl client configuration.

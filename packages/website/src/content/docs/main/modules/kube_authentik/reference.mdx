## Inputs

The following input variables are supported:

### akadmin\_email

Description: The email address to use for the root authentik administrator. Warning: must be changed manually once applied.

Type: `string`

Default: n/a

### authentik\_helm\_version

Description: The version of the Authentik helm chart to deploy

Type: `string`

Default: `"2024.10.5"`

### aws\_iam\_ip\_allow\_list

Description: A list of IPs that can use the service account token to authenticate with AWS API

Type: `list(string)`

Default: `[]`

### burstable\_nodes\_enabled

Description: Whether to allow pods to schedule on burstable nodes

Type: `bool`

Default: `true`

### cdn\_mode\_enabled

Description: Whether to enable CDN mode for the Vault ingress

Type: `bool`

Default: `true`

### cluster\_subnet\_ids

Description: Optional cluster subnet ids override; preserves the existing deployment default.

Type: `list(string)`

Default: `null`

### controller\_nodes\_enabled

Description: Whether to allow pods to schedule on EKS Node Group nodes (controller nodes)

Type: `bool`

Default: `true`

### db\_aws\_local\_endpoint

Description: Development simulators only: Pod-reachable S3 endpoint for database backups with static keys instead of IRSA. Null keeps AWS and IRSA.

Type: `string`

Default: `null`

### db\_az\_spread\_required

Description: Optional db az spread required override; preserves the existing deployment default.

Type: `bool`

Default: `true`

### db\_backup\_directory

Description: The name of the directory in the backup bucket containing the backups files.

Type: `string`

Default: `"initial"`

### db\_connection\_pooler\_enabled

Description: Whether Authentik connects through the transaction-mode PgBouncer pooler. False connects to the read-write Service directly, so migrations keep session semantics (advisory lock, search\_path, prepared statements).

Type: `bool`

Default: `true`

### db\_controller\_nodes\_enabled

Description: Optional db controller nodes enabled override; preserves the existing deployment default.

Type: `bool`

Default: `false`

### db\_initial\_storage\_gb

Description: Optional db initial storage gb override; preserves the existing deployment default.

Type: `number`

Default: `10`

### db\_instances

Description: Optional db instances override; preserves the existing deployment default.

Type: `number`

Default: `2`

### db\_kyverno\_cel\_policies\_enabled

Description: Whether the database uses Kyverno CEL policies instead of the legacy Kyverno policies. Null uses the kube\_pg\_cluster default.

Type: `bool`

Default: `null`

### db\_max\_slot\_wal\_keep\_size\_gb

Description: Database max\_slot\_wal\_keep\_size in GB; also added to the PVC size. Null uses the kube\_pg\_cluster default.

Type: `number`

Default: `null`

### db\_minimum\_memory\_mb

Description: Optional db minimum memory mb override; preserves the existing deployment default.

Type: `number`

Default: `1000`

### db\_node\_selector

Description: Required labels for database placement.

Type: `map(string)`

Default: `{}`

### db\_recovery\_directory

Description: The name of the directory in the backup bucket that contains the PostgreSQL backups and WAL archives

Type: `string`

Default: `null`

### db\_recovery\_mode\_enabled

Description: Whether to enable recovery mode for the PostgreSQL database

Type: `bool`

Default: `false`

### db\_recovery\_target\_time

Description: If provided, will recover the PostgreSQL database to the indicated target time in RFC 3339 format rather than to the latest data.

Type: `string`

Default: `null`

### db\_storage\_auto\_resize\_enabled

Description: Whether the database PVCs get the topolvm autoresize annotations. Disable on storage that cannot expand volumes. Null uses the kube\_pg\_cluster default.

Type: `bool`

Default: `null`

### db\_storage\_class\_name

Description: StorageClass for the database PVCs. Null uses the kube\_pg\_cluster default.

Type: `string`

Default: `null`

### db\_volume\_snapshot\_backups\_enabled

Description: Whether the database uses CSI VolumeSnapshot backups. Disable on storage without a snapshot driver. Null uses the kube\_pg\_cluster default.

Type: `bool`

Default: `null`

### db\_wal\_keep\_size\_gb

Description: Database wal\_keep\_size in GB. Null uses the kube\_pg\_cluster default.

Type: `number`

Default: `null`

### domain

Description: A list of domains from which authentik will serve traffic

Type: `string`

Default: `null`

### email\_from\_address

Description: The 'from' address to use for sent emails

Type: `string`

Default: n/a

### error\_reporting\_enabled

Description: True iff errors should be reported to Authentik for telemetry purposes

Type: `bool`

Default: `true`

### ingress\_enabled

Description: Whether to enable ingress to the Authentik server

Type: `bool`

Default: `false`

### ip\_restrictions\_enabled

Description: Optional ip restrictions enabled override; preserves the existing deployment default.

Type: `bool`

Default: `true`

### local\_gateway

Description: Local development only: attach an HTTPRoute for var.domain to this Gateway listener instead of using kube\_ingress. Null creates no route.

Type:

```hcl
object({
    name         = string
    namespace    = string
    section_name = string
  })
```

Default: `null`

### log\_level

Description: The log level for the Authentik pods

Type: `string`

Default: `"debug"`

### media\_reload\_enabled

Description: Whether Reloader rolls Authentik when the media ConfigMap changes. False annotates the ConfigMap with reloader.stakater.com/ignore; the directory volume still receives updates through the kubelet, so dependent modules can write media without restarting a single-replica server mid-apply.

Type: `bool`

Default: `true`

### monitoring\_enabled

Description: Whether to add active monitoring to the deployed systems

Type: `bool`

Default: `false`

### namespace

Description: Kubernetes namespace to deploy the resources into

Type: `string`

Default: `"authentik"`

### oidc\_issuer\_url

Description: Optional oidc issuer url override; preserves the existing deployment default.

Type: `string`

Default: `null`

### oidc\_provider\_arn

Description: Optional oidc provider arn override; preserves the existing deployment default.

Type: `string`

Default: `null`

### organization\_name

Description: The name of the organization for which Authentik serves as the IdP

Type: `string`

Default: n/a

### panfactum\_scheduler\_enabled

Description: Whether to use the Panfactum pod scheduler with enhanced bin-packing

Type: `bool`

Default: `true`

### pull\_through\_cache\_enabled

Description: Whether to use the ECR pull through cache for the deployed images

Type: `bool`

Default: `true`

### redis\_allow\_single\_node

Description: Optional redis allow single node override; preserves the existing deployment default.

Type: `bool`

Default: `false`

### redis\_controller\_nodes\_required

Description: Require retained controller placement for Redis.

Type: `bool`

Default: `false`

### redis\_enabled

Description: Whether to deploy Redis; Authentik 2025.10 and later do not use it.

Type: `bool`

Default: `true`

### redis\_replicas

Description: Optional redis replicas override; preserves the existing deployment default.

Type: `number`

Default: `3`

### server\_replicas

Description: Optional server replicas override; preserves the existing deployment default.

Type: `number`

Default: `2`

### sla\_target

Description: The Panfactum SLA level for the module deployment. 1 = lowest uptime (99.9%), lowest cost -- 3 = highest uptime (99.999%), highest Cost

Type: `number`

Default: `3`

### smtp\_host

Description: The SMTP server for email sending

Type: `string`

Default: n/a

### smtp\_password

Description: The password to use for SMTP authentication for email sending

Type: `string`

Default: n/a

### smtp\_port

Description: The SMTP server port for email sending.

Type: `number`

Default: `587`

### smtp\_use\_tls

Description: Whether Authentik uses STARTTLS to the SMTP server. Disable only for a local plaintext mail sink.

Type: `bool`

Default: `true`

### smtp\_user

Description: The user to use for SMTP authentication for email sending

Type: `string`

Default: n/a

### spot\_nodes\_enabled

Description: Whether to allow pods to schedule on spot nodes

Type: `bool`

Default: `true`

### vpa\_enabled

Description: Whether the VPA resources should be enabled

Type: `bool`

Default: `true`

### wait

Description: Wait for resources to be in a ready state before proceeding. Disabling this flag will allow upgrades to proceed faster but will disable automatic rollbacks. As a result, manual intervention may be required for deployment failures.

Type: `bool`

Default: `true`

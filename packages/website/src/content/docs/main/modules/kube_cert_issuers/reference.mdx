## Inputs

The following input variables are supported:

### alert\_email

Description: An email that will receive certificate alerts.

Type: `string`

Default: n/a

### aws\_iam\_ip\_allow\_list

Description: A list of IPs that can use the service account token to authenticate with AWS API

Type: `list(string)`

Default: `[]`

### cloudflare\_api\_token

Description: Cloudflare API Token

Type: `string`

Default: `null`

### cloudflare\_zones

Description: A list of public DNS domains managed by Cloudflare; cert-manager uses this to issue public-facing certificates.

Type: `list(string)`

Default: `[]`

### cluster\_subnet\_ids

Description: Explicit subnets for source-IP policy discovery.

Type: `set(string)`

Default: `null`

### ip\_restrictions\_enabled

Description: Enable source-IP deny policies.

Type: `bool`

Default: `true`

### kube\_domain

Description: The domain under which cluster utilities have subdomains registered.

Type: `string`

Default: n/a

### kyverno\_cel\_policies\_enabled

Description: Use policies.kyverno.io/v1 CEL policies, required by Kyverno 1.20+. Existing legacy policies must be migrated with a reviewed replacement plan.

Type: `bool`

Default: `false`

### namespace

Description: The name of the cert-manager namespace.

Type: `string`

Default: `"cert-manager"`

### oidc\_issuer\_url

Description: Existing OIDC issuer URL paired with its ARN.

Type: `string`

Default: `null`

### oidc\_provider\_arn

Description: Existing OIDC provider ARN; null retains EKS discovery.

Type: `string`

Default: `null`

### public\_issuer\_enabled

Description: Create the public Let's Encrypt ClusterIssuer and the ingress-tls Certificate. Disable for clusters without public DNS; the internal Vault issuers are unaffected.

Type: `bool`

Default: `true`

### route53\_zones

Description: A mapping of public DNS domains managed by AWS to their configuration; cert-manager uses this to issue public-facing certificates.

Type:

```hcl
map(object({
    record_manager_role_arn = string
    zone_id                 = string
  }))
```

Default: `{}`

### service\_account

Description: The name of the cert-manager service account.

Type: `string`

Default: `"cert-manager"`

### vault\_internal\_url

Description: The url to the vault instance for internal cert issuance

Type: `string`

Default: n/a

## Outputs

The following outputs are exported:

### cloudflare\_zones

Description: The cloudflare DNS names provided as an input

### kyverno\_cel\_policy\_documents

Description: CEL policy manifests for migration validation.

### route53\_zones

Description: The route53 zone configuration provided as an input

### vault\_ca\_crt

Description: The public certificate of the root vault certificate authority

## Inputs

The following input variables are supported:

### aws\_iam\_ip\_allow\_list

Description: A list of IPs that can use the service account token to authenticate with AWS API

Type: `list(string)`

Default: `[]`

### aws\_iam\_ip\_restrictions\_enabled

Description: Enable source-IP restrictions for legacy deployments. The scoped Talos ENI path uses ENI policy and OIDC restrictions.

Type: `bool`

Default: `true`

### burstable\_nodes\_enabled

Description: Whether to allow controller pods to schedule on burstable nodes. Does not affect DaemonSet pods.

Type: `bool`

Default: `true`

### cilium\_helm\_version

Description: The version of the cilium helm chart to deploy

Type: `string`

Default: `"1.20.4"`

### cluster

Description: Cluster identity. The aws\_eks type uses EKS ENI and IRSA defaults. The talos type discovers ENI networking and OIDC from the named cluster.

Type:

```hcl
object({
    type = string
    name = string
  })
```

Default: `null`

### cluster\_name

Description: Operator cluster name override. Null uses the Panfactum metadata cluster name; local clusters have none, so they set it.

Type: `string`

Default: `null`

### cluster\_pool\_ipv4\_cidrs

Description: Pod CIDRs used only by cluster-pool IPAM. Must match the installed cluster during adoption.

Type: `list(string)`

Default:

```json
[
  "10.244.0.0/16"
]
```

### cluster\_type

Description: Legacy platform input. EKS is the default. Local (kind) requires an explicit API host and port.

Type: `string`

Default: `null`

### controller\_nodes\_enabled

Description: Whether to allow controller pods to schedule on EKS Node Group nodes (controller nodes). Does not affect DaemonSet pods.

Type: `bool`

Default: `true`

### eni\_cluster\_tag

Description: Unique cluster ownership tag for Talos ENI allocation and garbage collection. Required for Talos ENI.

Type: `string`

Default: `null`

### eni\_first\_interface\_index

Description: First interface index available for pod IP allocation.

Type: `number`

Default: `null`

### eni\_subnet\_ids\_filter

Description: Restrict newly allocated ENIs to these subnet IDs.

Type: `list(string)`

Default: `[]`

### envoy\_enabled

Description: Enable the standalone Envoy DaemonSet. Defaults to false for scoped Talos ENI and non-Talos deployments.

Type: `bool`

Default: `null`

### hubble\_enabled

Description: Whether to enable hubble for network debugging

Type: `bool`

Default: `false`

### ipam\_mode

Description: Optional IPAM override. Defaults to eni on EKS and on Talos when using the cluster object. Legacy Talos and local default to cluster-pool.

Type: `string`

Default: `null`

### ipv4\_native\_routing\_cidr

Description: CIDR reachable without masquerading or tunnelling. Required by Cilium for native routing outside ENI IPAM.

Type: `string`

Default: `null`

### k8s\_service\_host

Description: Agent API host override, without scheme. Defaults to the EKS endpoint or Talos KubePrism localhost.

Type: `string`

Default: `null`

### k8s\_service\_port

Description: Agent API port override. Defaults to 443 for EKS and 7445 for Talos KubePrism.

Type: `number`

Default: `null`

### l7\_proxy\_enabled

Description: Enable Cilium application-layer policies and visibility. Defaults to false on scoped Talos ENI clusters and true otherwise.

Type: `bool`

Default: `null`

### log\_level

Description: The log level for the Cilium pods

Type: `string`

Default: `"warn"`

### monitoring\_enabled

Description: Whether to add active monitoring to the deployed systems

Type: `bool`

Default: `false`

### namespace

Description: Helm release namespace. For adoption, preserve the existing release namespace.

Type: `string`

Default: `"cilium"`

### namespace\_create

Description: Manage the namespace and its Panfactum RBAC. Set false to use an existing namespace such as kube-system.

Type: `bool`

Default: `true`

### namespace\_labels

Description: Additional labels for the managed namespace, including Pod Security Admission labels.

Type: `map(string)`

Default: `{}`

### oidc\_issuer\_url

Description: HTTPS issuer URL paired with oidc\_provider\_arn. Custom identities require the exact namespace/service-account subject and sts.amazonaws.com audience.

Type: `string`

Default: `null`

### oidc\_provider\_arn

Description: Existing self-managed cluster OIDC provider ARN. Supply with oidc\_issuer\_url; null preserves EKS discovery.

Type: `string`

Default: `null`

### operator\_replicas

Description: Operator replica override. Defaults to two on EKS and on discovered Talos ENI clusters with SLA target 2 or higher, one otherwise.

Type: `number`

Default: `null`

### pull\_through\_cache\_enabled

Description: Whether to use the ECR pull through cache for the deployed images

Type: `bool`

Default: `null`

### routing\_mode

Description: Optional Cilium routing mode override. Defaults to native with ENI IPAM and tunnel otherwise.

Type: `string`

Default: `null`

### sla\_target

Description: The Panfactum SLA level for the module deployment. 1 = lowest uptime (99.9%), lowest cost -- 3 = highest uptime (99.999%), highest Cost

Type: `number`

Default: `3`

### spot\_nodes\_enabled

Description: Whether to allow controller pods to schedule on spot nodes. Does not affect DaemonSet pods.

Type: `bool`

Default: `true`

### values\_overrides

Description: Additional Helm values documents merged after module defaults. Review their full diff when adopting an existing release.

Type: `list(string)`

Default: `[]`

### vpa\_enabled

Description: Whether the VPA resources should be enabled

Type: `bool`

Default: `false`

### wait

Description: Wait for resources to be in a ready state before proceeding. Disabling this flag will allow upgrades to proceed faster but will disable automatic rollbacks. As a result, manual intervention may be required for deployment failures.

Type: `bool`

Default: `true`

## Outputs

No outputs.

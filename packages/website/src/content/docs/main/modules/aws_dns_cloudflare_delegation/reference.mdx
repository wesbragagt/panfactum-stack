## Inputs

The following input variables are supported:

### cloudflare\_api\_token

Description: Cloudflare API token with DNS edit permission on the parent zones.

Type: `string`

Default: n/a

### delegations

Description: Subdomains to delegate (keys, e.g. homelab.example.com) with the Cloudflare zone ID of their parent domain and the Route53 name servers that should serve them (from aws\_dns\_zones).

Type:

```hcl
map(object({
    zone_id      = string
    name_servers = list(string)
  }))
```

Default: n/a

## Outputs

The following outputs are exported:

### delegated\_domains

Description: Subdomains delegated to Route53 and the name servers their NS records point to.

## Providers

The following providers are needed by this module:

- cloudflare (5.28.1)

## Inputs

The following input variables are supported:

### admin\_iam\_arns

Description: List of IAM arns for encryption key admins.

Type: `list(string)`

Default: `[]`

### aws\_iam\_ip\_allow\_list

Description: A list of IPs that can use the service account token to authenticate with AWS API

Type: `list(string)`

Default: `[]`

### aws\_local\_endpoint

Description: Development simulators only: Pod-reachable AWS endpoint for KMS unseal and the AWS plugins. Enables static IAM-user credentials instead of IRSA. Null keeps AWS and IRSA.

Type: `string`

Default: `null`

### az\_spread\_required

Description: Require AZ spread for stateful replicas. Disable only for an explicit single-zone/single-node deployment.

Type: `bool`

Default: `true`

### bootstrap\_mode\_enabled

Description: Whether the cluster is being bootstrapped and does not yet have the autoscaler enabled

Type: `bool`

Default: `false`

### burstable\_nodes\_enabled

Description: Whether to allow pods to schedule on burstable nodes

Type: `bool`

Default: `true`

### cdn\_mode\_enabled

Description: Whether to enable CDN mode for the Vault ingress

Type: `bool`

Default: `true`

### cluster\_subnet\_ids

Description: Explicit subnets for source-IP policy discovery.

Type: `set(string)`

Default: `null`

### controller\_nodes\_enabled

Description: Whether to allow pods to schedule on EKS Node Group nodes (controller nodes)

Type: `bool`

Default: `true`

### cors\_enabled

Description: Whether to enable CORS handling in the Vault ingress

Type: `bool`

Default: `false`

### cors\_extra\_allowed\_origins

Description: Extra allowed origins for CORS handling

Type: `list(string)`

Default: `[]`

### disable\_mlock

Description: Optional explicit mlock setting for Raft on hosts without swap. Null preserves the existing template.

Type: `bool`

Default: `null`

### extra\_helm\_values

Description: Explicit chart overrides merged last. Empty preserves existing module values.

Type: `any`

Default: `{}`

### ingress\_enabled

Description: Whether or not to enable the ingress for routing traffic to vault

Type: `bool`

Default: `false`

### ip\_restrictions\_enabled

Description: Enable source-IP deny policies.

Type: `bool`

Default: `true`

### kyverno\_cel\_policies\_enabled

Description: Use policies.kyverno.io/v1 CEL policies, required by Kyverno 1.20+. Existing legacy policies must be migrated with a reviewed replacement plan.

Type: `bool`

Default: `false`

### log\_level

Description: The log level for Vault pods. Must be one of: trace, debug, info, warn, error.

Type: `string`

Default: `"warn"`

### monitoring\_enabled

Description: Whether to allow monitoring CRs to be deployed in the namespace

Type: `bool`

Default: `false`

### oidc\_issuer\_url

Description: Existing OIDC issuer URL paired with its ARN.

Type: `string`

Default: `null`

### oidc\_provider\_arn

Description: Existing OIDC provider ARN; null retains EKS discovery.

Type: `string`

Default: `null`

### openbao\_plugin\_arch

Description: CPU architecture of the OpenBao server nodes and its AWS plugin binaries. OpenBao pins one binary checksum per plugin, so the server runs only on this architecture.

Type: `string`

Default: `"arm64"`

### panfactum\_scheduler\_enabled

Description: Whether to use the Panfactum pod scheduler with enhanced bin-packing

Type: `bool`

Default: `false`

### pull\_through\_cache\_enabled

Description: Whether to use the ECR pull through cache for the deployed images

Type: `bool`

Default: `true`

### reader\_iam\_arns

Description: List of IAM arns for users who can use the encryption key for encryption and decryption.

Type: `list(string)`

Default: `[]`

### restricted\_reader\_iam\_arns

Description: List of IAM arns for users who can only view the encryption key.

Type: `list(string)`

Default: `[]`

### secrets\_engine

Description: Secrets server implementation. Vault remains the default; OpenBao preserves the Vault-facing service contract.

Type: `string`

Default: `"vault"`

### sla\_target

Description: The Panfactum SLA level for the module deployment. 1 = lowest uptime (99.9%), lowest cost -- 3 = highest uptime (99.999%), highest Cost

Type: `number`

Default: `3`

### spot\_nodes\_enabled

Description: Whether to allow pods to schedule on spot nodes

Type: `bool`

Default: `true`

### superuser\_iam\_arns

Description: List of IAM arns for encryption key superusers.

Type: `list(string)`

Default: `[]`

### vault\_domain

Description: The public domain for the Vault cluster

Type: `string`

Default: n/a

### vault\_helm\_version

Description: The version of the vault helm chart to deploy

Type: `string`

Default: `"0.27.0"`

### vault\_image\_tag

Description: The version of vault to use

Type: `string`

Default: `"1.14.7"`

### vault\_replicas

Description: Number of Raft members. One is explicitly non-HA; default three preserves existing topology.

Type: `number`

Default: `3`

### vault\_storage\_increase\_gb

Description: The GB to increase storage by if free space drops below the threshold

Type: `number`

Default: `1`

### vault\_storage\_increase\_threshold\_percent

Description: Dropping below this percent of free storage will trigger an automatic increase in storage size

Type: `number`

Default: `20`

### vault\_storage\_limit\_gb

Description: The maximum number of gigabytes of storage to provision for the postgres cluster

Type: `number`

Default: `null`

### vault\_storage\_size\_gb

Description: The number of gigabytes to allocate to vault storage.

Type: `number`

Default: `20`

### vpa\_enabled

Description: Whether the VPA resources should be enabled

Type: `bool`

Default: `false`

### wait

Description: Wait for resources to be in a ready state before proceeding. Disabling this flag will allow upgrades to proceed faster but will disable automatic rollbacks. As a result, manual intervention may be required for deployment failures.

Type: `bool`

Default: `true`

### x\_forwarded\_for\_authorized\_addrs

Description: CIDRs of the proxies whose X-Forwarded-For header the server trusts; requests through any other proxy are rejected

Type: `string`

Default: `"10.0.0.0/16"`

## Outputs

The following outputs are exported:

### vault\_domain

Description: n/a

## Inputs

The following input variables are supported:

### aws\_endpoint

Description: Development simulators only: IAM/STS endpoint the OpenBao AWS secrets engine calls, reachable from the OpenBao Pod. Null keeps the AWS defaults.

Type: `string`

Default: `null`

### aws\_secrets\_use\_workload\_identity

Description: Use the Vault pod AWS SDK web identity for the AWS secrets backend, attaching its existing user-management policy to the annotated Vault role. False preserves legacy IAM user/access-key resources.

Type: `bool`

Default: `false`

### burstable\_nodes\_enabled

Description: Whether to allow pods to schedule on burstable nodes

Type: `bool`

Default: `true`

### controller\_nodes\_enabled

Description: Whether to allow pods to schedule on EKS Node Group nodes (controller nodes)

Type: `bool`

Default: `true`

### kubernetes\_issuer

Description: Explicit issuer of projected Kubernetes tokens for self-managed clusters. Null retains the provider default.

Type: `string`

Default: `null`

### kubernetes\_url

Description: The url to the kubernetes API server

Type: `string`

Default: n/a

### log\_level

Description: The log level for the vault-secrets-operators pods

Type: `string`

Default: `"error"`

### pull\_through\_cache\_enabled

Description: Whether to use the ECR pull through cache for the deployed images

Type: `bool`

Default: `true`

### spot\_nodes\_enabled

Description: Whether to allow pods to schedule on spot nodes

Type: `bool`

Default: `true`

### vault\_api\_namespace

Description: API namespace the Vault Secrets Operator sends with requests. Null keeps the Kubernetes namespace name (vault); OpenBao's root namespace is the empty string.

Type: `string`

Default: `null`

### vault\_internal\_url

Description: The internal url of the vault instance

Type: `string`

Default: n/a

### vault\_secrets\_operator\_helm\_version

Description: The version of the vault-secrets-operator helm chart to deploy

Type: `string`

Default: `"2.0.0"`

### vault\_secrets\_operator\_replicas

Description: n/a

Type: `number`

Default: `1`

### vpa\_enabled

Description: Whether the VPA resources should be enabled

Type: `bool`

Default: `false`

### wait

Description: Wait for resources to be in a ready state before proceeding. Disabling this flag will allow upgrades to proceed faster but will disable automatic rollbacks. As a result, manual intervention may be required for deployment failures.

Type: `bool`

Default: `true`

## Outputs

No outputs.
